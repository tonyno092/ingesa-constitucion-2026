# Constitución INGESA · páginas de estudio

Repositorio para publicar en GitHub Pages las herramientas interactivas del Tema 1.

- `index.html`: portada con acceso a las versiones móviles y de pantalla amplia.
- `Entrenador_Test_Constitucion_INGESA_2026.html`: entrenador de preguntas original.
- `Aprende_Articulos_Constitucion_INGESA_2026.html`: mapa de artículos original.
- `test-constitucion-ingesa.html`: versión móvil táctil del entrenador.
- `articulos-constitucion-ingesa.html`: versión móvil táctil del mapa.

Las versiones móviles se adaptan al viewport del Galaxy S26 Ultra; no fijan una resolución física de 3120 × 1440 px. La pantalla QHD+ de 6,9 pulgadas se escala desde el navegador.

Para activar GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
